# Anvira Notes 1.2.44

A fix for shared notes in Messages.

## Fixed
- **Shared notes open again:** tapping **Open** (or **Look inside** on a shared notebook) on a page someone shared in a chat now shows it over the whole window. Before, the preview got squeezed into the small card and flickered, so the note seemed not to open.
- **No more lag while it is open:** the flicker kept redrawing the blurred background behind the preview, which slowed the whole app down. That is gone.
- **Double-click to select:** double-clicking a word in a shared page's preview now selects it, instead of sending a ❤️ to the message underneath.
- The photo viewer in Messages always fills the window too.
