## Anvira Notes 1.0.0

Notes and Study in one app, powered by **Anvira Runtime** (local AI on your PC). A LocalHouseLLM product.

### Notes
- Notion-style pages with cover, icon, blocks, sub-pages, tags, backlinks and version history; Google Docs-style menus, formatting and page layout.
- Templates: 22 included, plus a web library (Good Docs Project, Obsidian collections, README and decision-record templates, or any GitHub repository or file link) and your own.
- Find and replace, outline, quick switcher, whiteboard, spreadsheet, charts and diagrams.
- Export to PDF (cover, icon, charts, diagrams, callouts and more), Markdown, HTML and text.
- Ask AI, summaries, writing help and grounded answers from your own sources (PDF, PowerPoint, Word, Excel, images).

### Study
- A learning path of lessons made from your own notes and files: flashcards with spaced repetition, quizzes with explanations, practice problems, timed exams.
- **Study from a file**: drop in a PDF, deck or document and turn it into lessons. Lessons tell you when their notes have changed and update without losing progress.
- Daily goal, streak, XP, achievements, weak spots and a plan for exam day.

### Also
- **AI & Models** in Settings, with the Hugging Face model library (filters, fit badges, downloads), like Anvira.
- **Updates by themselves**: a small button at the top right for the app and another for Anvira Runtime. Nothing downloads or restarts until you click.
- **Optional account**: sign in or create one from the side bar. Notes and Study work fully without it.
- A thin side bar that grows when you point at it.

### Install
Download **Anvira-Notes-Setup-1.0.0.exe** and run it (per-user, no administrator rights). Windows may show a SmartScreen notice because the installer is not code-signed yet: **More info → Run anyway**. On first launch Notes offers to set up Anvira Runtime, then you pick a model.
