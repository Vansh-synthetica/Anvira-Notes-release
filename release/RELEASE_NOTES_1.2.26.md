### New: Code Lab
A new lab in **Study → Labs and exams** for learning to code, step by step, the way Mimo and Sololearn teach it. It covers **Python, JavaScript, Java, C and C++**, and it works offline: your code really runs, right inside the app.

- **Learn:** short lessons on a path. Read and run an example, answer "what does this print?", fill in the blanks, then write the program yourself. Your code is checked by running it. When it is wrong, you see what was expected next to what your program printed, with the wrong line marked.
- **Practice:** 12 challenges, from easy to hard (FizzBuzz, palindromes, primes, a Caesar cipher, balanced brackets…). Solve each one in any of the five languages. Run tries your own input; Submit checks every test.
- **Playground:** write anything, give it input, and run it, with example programs for each language.
- **Ask Pochi:** a hint that doesn't give the answer away, an explanation of your code, or an explanation of an error (uses the AI model on your PC).
- Every lesson example, answer and challenge solution was checked by running it in all five languages before release.

### Your Pochi, everywhere
The Pochi you dress up in **Pochi Club** (its colour and what it wears) now appears everywhere Pochi does: the Study desk, lessons, quizzes, flashcards, mock exams and the chat panels. It is no longer only in the small Club badge.
