# Anvira Notes 1.2.42

A small fix for how the window looks while a dialog is open.

## Fixed
- **Even dimming behind dialogs:** when a dialog opens, the side rail now darkens with the rest of the window, so there's no bright strip down the left edge.
- **Window buttons match:** the minimise, maximise and close buttons darken too, so the top-right corner no longer shows a lighter box.

This works with both the usual look and the Mac-style look preview (Settings → Look).
