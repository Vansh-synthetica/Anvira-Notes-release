# Anvira Notes 1.2.30

A release all about the Notes section: every part of it was gone through, fixed and smoothed.

## Pages in the sidebar
- Right-click a page (or use its ⋯ button) for Rename, Add sub-page, Duplicate, Move out to top level, Move to another notebook, Favourites and Move to trash.
- Double-click a page to rename it. The sidebar follows the title as you type it.
- Drag pages to reorder them, or drop one onto another to make it a sub-page.
- A new page puts the cursor straight in its title.
- An empty notebook offers a text page, a whiteboard, a sheet or a template.
- Recent and Favourites show the right icon for boards and sheets.

## Writing
- The selection toolbar has Bold, Italic, Underline, Strike, Code, Highlight and Link, plus an "Ask AI" menu for rewriting.
- Text colour and highlight use a palette that stays readable in dark and light mode (old highlights included).
- Checkboxes, numbered lists and code are clearer in both themes; tables no longer vanish in light mode.
- Code blocks have a language picker and a Copy button.
- Toggles: Enter in the heading starts a line inside, Backspace on an empty toggle turns it back into a line, and closing a toggle no longer hides its heading.
- Spell check: "Add to dictionary", a working "Ignore", and code is no longer marked as misspelled.
- The "/" menu shows what each block is for.

## Sheets
- Sheets follow the dark or light theme instead of always being white.
- Every change is saved, including column widths, row heights, merged cells and new or renamed tabs (only cell values were saved before).

## Ask AI and the rest
- Ask AI has a clear mode switch (Notebook, Edit page, Web, All notes) and suggested questions to start from.
- Page history previews read cleanly.
- PDF and CSV export tell you when the file was saved, or why it was not.

## Motion
- Small animations where things used to just appear: the selection toolbar, spelling popup, outline, sub-pages, new pages, Ask AI messages, opening toggles and ticking a to-do. They switch off when Windows is set to reduce motion.
