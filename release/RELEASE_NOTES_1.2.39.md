# Anvira Notes 1.2.39

Speaker labels and page edits work again.

## Record a lecture
- **Label speakers** works again. The open-source project behind the speaker model updated its file on 19 November, and from then on the download was turned down with "did not match its checksum". Anvira now accepts the new version as well as the old one, so labels that already work keep working.

## Edit page
- Asking the AI to rewrite a page no longer shows a jumble of code in the chat. When the AI's edits contained quoted titles or line breaks, Anvira couldn't read them and showed them as text instead. It now reads them and applies the changes. If an edit still can't be used, you're told plainly that nothing was changed.
